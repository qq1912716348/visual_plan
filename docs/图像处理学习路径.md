# 图像处理学习路径

按下面两份材料的知识点排列。每一课先读教程里写明的目标，再用书里对应的脚本改一个参数、看图像哪里变了。学完一课再进入下一课。

## 怎么学一课

1. 打开该课列出的教程文件，只读「目标」和「理论」。
2. 用一句话写下：这个操作改的是像素值、邻域、几何，还是跨图像的对应关系。
3. 若该课有书的脚本，运行它，然后只改一个参数（核大小、阈值、缩放比例），对比前后图像。
4. 做教程末尾的练习。做不出来就停在这一课，不跳到人脸或跟踪。

## 阶段 1 · 图像和视频进得来

来源：`SecondSection/1_1`、`1_2`，`ThirdSection/2_1` 至 `2_5`；书 `01-图像的基本操作/`。

要理解的事：

- 图像在内存里是 NumPy 数组。灰度图是二维，彩色图通常是 BGR 三维数组，通道顺序是蓝、绿、红。
- `imread` 的标志决定读成灰度、原图，或缩小后再读。`imwrite` 把数组写回文件。
- 窗口用 `imshow` 显示，`waitKey` 负责刷新并读取按键。不调用 `waitKey`，窗口不会正常更新。
- 视频是连续的帧。`VideoCapture` 打开摄像头或文件，循环里每次读一帧；`VideoWriter` 用 fourcc 编码把帧写成文件。
- 绘图是在数组上改像素：线、矩形、圆、椭圆、多边形、文字。
- 鼠标回调和轨迹条是同一类东西：事件或滑块改变一个数，下一帧用这个数重画。

对应脚本：

- `image_readwrite.py`：灰度读入、缩小读入、写文件。
- `video_read.py`：摄像头或视频文件逐帧显示。
- `video_write.py`：生成画面并写成视频。
- `video_read_3dcam.py`：奥比中光深度相机，没有该相机就跳过。

本阶段先在 Windows 上安装 OpenCV-Python（教程 `1_2`）。Fedora、Ubuntu 和从源码编译的两节先不看。

## 阶段 2 · 像素和算术

来源：`FourthSection/3_1`、`3_2`、`3_3`。

要理解的事：

- 用数组下标读、改单个像素；用切片取一块区域，这块区域叫 ROI。
- `shape`、`dtype`、像素总数是图像的基本属性。通道可以用 NumPy 拆开再合并。
- `copyMakeBorder` 给图像加边，后面做卷积时会用到边界怎么补。
- OpenCV 的加法和 NumPy 的加法不同：像素相加会饱和在 255，NumPy 加法按数据类型回绕。
- `addWeighted` 是两张图按权重混合。按位与、或、非用来做掩码，教程用它把 logo 嵌进另一张图。
- `getTickCount` / `getTickFrequency` 用来量一段处理花了多少时间。图像处理的循环很重，先学会量，再谈快慢。

这一阶段没有单独的书脚本，在 Python 里对一张图做切片、加法和掩码即可。

## 阶段 3 · 颜色、阈值、几何

来源：`FifthSection/4_1`、`4_2`、`4_3`；书 `02-图像的几何变换/`。

要理解的事：

- `cvtColor` 在颜色空间之间转换。追踪有颜色的物体时，转到 HSV，再用 `inRange` 取出色调范围内的像素。
- 简单阈值用一个全局门限把灰度分成两类。自适应阈值对每个小块单独取门限，光照不匀时更稳。
- Otsu 在双峰直方图上自动找门限，使类间方差最大。教程给出了用直方图和累积分布自己算这个门限的步骤，这一课要跟着算一遍，不要只调用 `threshold`。
- 缩放要选插值：最近邻、线性、三次、Lanczos。翻转、绕中心旋转、平移都是仿射变换，用 `warpAffine`。
- 仿射由三对点确定（`getAffineTransform`）。透视（单应性）由四对点或估计得到的矩阵确定，用 `warpPerspective`。

对应脚本：

- `image_transforms.py`：翻转、旋转、平移，以及四种插值。
- `image_affine.py`：三对点求仿射矩阵再变换。
- `image_homography.py`：估计单应性矩阵再做透视变换。

## 阶段 4 · 邻域：滤波、形态学、边缘

来源：`FifthSection/4_4` 至 `4_8`；书 `03-图像滤波/image_filtering.py`、`04-边缘检测/`。

这是算法学习的核心。每一课都要能说出「每个输出像素由哪些输入像素决定」。

### 平滑

教程 `4_4` 的目标是用低通滤波模糊图像，并把自定义核用于二维卷积。书的脚本对泊松噪声图和高斯/椒盐噪声图分别做了这些：

- 均值滤波 `blur`：邻域取平均，核越大越糊。
- 高斯滤波 `GaussianBlur`：中心权重大。核大小和 sigma 是两个不同的旋钮，脚本里 3×3、5×5，以及 sigma 为 0 和为 2 的结果要并排看。
- 中值滤波 `medianBlur`：用邻域中值替换中心，适合椒盐噪声。
- 双边滤波 `bilateralFilter`：颜色差太大的邻居权重变小，所以边缘比高斯滤波保得住。

自定义核用 `filter2D`。这一课用 NumPy 自己写一个 3×3 均值，再和 `blur` 的结果比。

### 形态学

来源：`4_5_形态转换.md`。操作作用在形状上，输入是图像和结构元素（矩形、椭圆、十字）。

- 腐蚀：结构元素放不进前景就把该点去掉，前景变瘦。
- 膨胀：结构元素碰到前景就把该点补上，前景变胖。
- 开运算：先腐蚀后膨胀，去掉小亮斑。
- 闭运算：先膨胀后腐蚀，补上小黑洞。
- 形态学梯度：膨胀减腐蚀，得到轮廓带。
- 顶帽：原图减开运算，留下比结构元素小的亮细节。
- 黑帽：闭运算减原图，留下比结构元素小的暗细节。

### 梯度

来源：`4_6_图像梯度.md`；书 `edges.py`。

- Sobel：用差分核估计 x 或 y 方向的一阶导。
- Scharr：同一件事，核的系数更强调中心。
- Laplacian：二阶导，对各个方向的突变都有响应。
- 输出不能直接用 8 位无符号整数。负梯度会被截成 0。教程要求先用有符号或浮点类型，再取绝对值和 `convertScaleAbs`。书的注释写的是同一件事。

### Canny

来源：`4_7_Canny边缘检测.md`；书 `canny.py`。Canny 是四步，顺序不能换：

1. 用高斯滤波降噪。教程写的是 5×5。
2. 用 Sobel 求梯度幅值和方向。方向量化到水平、垂直和两条对角线。
3. 非极大值抑制：沿梯度方向只保留局部最大，边缘变细。
4. 滞后阈值：高于高阈值的留下；低于低阈值的丢掉；介于两者之间的，只有连到强边缘才留下。

书的脚本把高阈值设成低阈值的 3 倍，先转灰度、再高斯、再 Canny，并用轨迹条改低阈值。把低阈值从很小拖到很大，看弱边缘怎么消失。

### 金字塔

来源：`4_8_图像金字塔.md`。`pyrDown` 缩小并平滑，`pyrUp` 放大。高斯金字塔逐层缩小；拉普拉斯金字塔是相邻两层的差，保存被平滑掉的细节。教程用两层金字塔把两张图各取一半融成一张。这一课先把「缩小再放大回不了原图」看清楚。

## 阶段 5 · 轮廓

来源：`FifthSection/4_9_1` 至 `4_9_5`。书没有单独一章，后面机械臂抓取脚本 `pickup_simple.py` 会用到 `findContours`。

要理解的事：

- 轮廓是边界点的序列。先二值化，再用 `findContours` 找，用 `drawContours` 画。
- 近似方法决定点存得多细。
- 能算的量：矩、面积、周长、多边形近似、凸包、是否凸、正矩形、旋转矩形、最小外接圆、拟合椭圆、拟合直线。
- 由这些量派生的形状描述：长宽比、范围（轮廓面积 / 外接矩形面积）、坚实度（轮廓面积 / 凸包面积）、等效直径、方向、极值点。
- 凸缺陷是凸包和轮廓之间的凹陷，点到轮廓的距离、形状匹配在 `4_9_4`。
- 轮廓有父子层级。四种检索模式：`RETR_LIST` 不要层级，`RETR_EXTERNAL` 只要最外层，`RETR_CCOMP` 两层，`RETR_TREE` 整棵树。

## 阶段 6 · 直方图、频率、几何检测、分割

来源：`FifthSection/4_10_1` 至 `4_16`。

| 课 | 要理解的事 | 教程文件 |
| --- | --- | --- |
| 直方图 | 统计每个灰度（或每个颜色）有多少像素。`calcHist` 与 `np.histogram` 都要会。掩码让统计只发生在一块区域里 | `4_10_1` |
| 均衡 | 把直方图拉平，提高对比。CLAHE 在小块上做均衡，再用对比度上限压住噪声放大 | `4_10_2` |
| 二维直方图 | 两个通道联合统计，例如色调和饱和度。后面反投影用它描述「这种颜色长什么样」 | `4_10_3` |
| 反投影 | 用对象的颜色直方图去整张图上打分，得分高的像素更像对象。教程先用 NumPy 写算法，再用 OpenCV | `4_10_4` |
| 傅里叶 | 图像的二维 DFT。边缘和噪声是高频，平缓区域是低频。低通核在频域中心有能量，拉普拉斯、Sobel、Scharr 是高通。要会 `dft` / `idft`，也要会 NumPy 的 FFT | `4_11` |
| 模板匹配 | 拿一块小图在大图上滑动比较。六种比较函数用 `matchTemplate`，位置用 `minMaxLoc`。多对象时在响应图上找多个峰 | `4_12` |
| 霍夫直线 | 边缘点投票到参数空间，票数高的是直线。标准霍夫和概率霍夫（`HoughLines`、`HoughLinesP`）都要跑 | `4_13` |
| 霍夫圆 | 同一思想用到圆心和半径 | `4_14` |
| 分水岭 | 把图像想成地形，从标记注水。标记来自确定的前景、确定的背景，以及两者之间的未知带 | `4_15` |
| GrabCut | 用一个矩形或笔触给出前景/背景的初步标记，迭代地把像素分成前景和背景 | `4_16` |

反投影和傅里叶这两课，教程本身就要求看 NumPy 实现。这两课以读懂 NumPy 版本为准，OpenCV 调用用来核对结果。

## 阶段 7 · 特征：从角点到把物体找出来

来源：`Sixth/5_1` 至 `5_10`；书 `05-特征提取与匹配/`。

一条链，按这个顺序：

1. 特征是图像里容易再次找到的点，再加上描述这个点周围的向量（`5_1`）。
2. Harris 角点对旋转稳定，对缩放不稳定（`5_2`）。亚像素用 `cornerSubPix` 把角点推到更细的位置。
3. Shi-Tomasi 是 Harris 的一个打分变体，后面光流用它选跟踪点（`5_3`）。
4. SIFT 补上尺度不变：尺度空间极值、关键点定位、方向分配、描述子（`5_4`）。书的 `sift.py` 画出关键点的大小和方向。
5. SURF 用积分图加速近似，只读 `5_5`，不作为必跑代码。
6. FAST 看圆周上的像素是否连续比中心亮或暗，速度快；非极大值抑制去掉挤在一起的点（`5_6`）。
7. BRIEF 用点对的亮度比较做成二进制描述子，本身没有方向（`5_7`）。
8. ORB 把带方向的 FAST 和旋转后的 BRIEF 合在一起，免费、可实时（`5_8`）。书的 `orb.py` 只做关键点。
9. 匹配：暴力匹配逐个比描述子；FLANN 用近似最近邻。SIFT 用 Lowe 的比例测试丢掉含糊匹配（`5_9`）。书有 `bfmatch.py` 和 `flann.py`。
10. 足够多的好匹配可以估计单应性，把物体在场景里的轮廓框出来（`5_10`）。书的 `app.py` 把 SIFT、FLANN、比例测试、RANSAC 单应性串成这一条。

阶段 7 的完成标准是把 `app.py` 的四步用自己的话讲通：提特征、匹配、按比例留下好匹配、用内点求单应性。

## 阶段 8 · 视频里的运动

来源：`Seventh/6_1`、`6_2`、`6_3`；书 `07-目标跟踪应用/meanshift.py`、`camshift.py`。

- 背景减除：用一段视频估计背景模型，新帧里对不上模型的像素当成前景。教程比较几种背景模型，并说明它们对阴影和光照的差别。
- MeanShift：用目标区域的颜色直方图做反投影，迭代地把窗口中心挪到概率质量的中心。窗口大小不变。
- CamShift：在 MeanShift 上更新窗口的大小和朝向，目标变近变远时框能跟着变。
- Lucas-Kanade 光流：假设小窗口里的运动一样，用亮度恒定和邻域方程求位移。点用 Shi-Tomasi 选出。稠密光流则给每个像素一个运动向量。

`dasiamrpn.py` 和 `demo.py` 是深度学习跟踪器，放到阶段 12，不插进这一课。

## 阶段 9 · 相机和三维

来源：`Eighth/7_1` 至 `7_4`。需要标定板图片，没有标定板时先读理论，实验可以后补。

- 镜头畸变有径向和切向两类。标定求出内参、畸变系数和外参，再用 `undistort` 或重映射把图像拉直。重投影误差用来看标定好不好。
- 有了内参，可以用已知的三维点把坐标轴或简单物体画进图像，这是姿态估计。
- 对极几何：两张图的对应点满足极线约束。极点、极线要用一对图像画出来。教程用 SIFT、FLANN 和比例测试找对应点，再算极线。
- 立体匹配把左右图像素对应起来，视差再换成深度。

## 阶段 10 · 三个经典学习器

来源：`Ninth/8_1` 至 `8_6`。

- kNN：新样本的类别由最近的 k 个训练样本投票。教程用二维点演示，再用 OpenCV 自带的手写数字和字母做 OCR。
- SVM：在两类之间找间隔最大的分界面。线性分不开时用核把数据映射开。同一份手写数字改用 SVM 再做一次，用来对比 kNN。
- K 均值：把数据分成 k 团，交替更新中心和归属。教程的三个用途是数据分组、图像量化前的特征压缩、用少数颜色重画一张图。

这三个算法服务「看懂分类和聚类」，不是这条路径里的文字识别终点。书的文字识别用的是检测网络加 CRNN，在阶段 12。

## 阶段 11 · 计算摄影

来源：`Tenth/9_1`、`9_2`、`9_3`。

- 非局部均值去噪：噪声近似零均值。在整张图里找相似的小块一起平均，而不是只对紧邻的像素做模糊。彩色图先转到 CIELAB，再对亮度和色度分别处理。
- 图像修补：用周围像素把掩码标出的破损或遮挡补上。
- HDR：多张不同曝光合成高动态范围，再色调映射到 8 位可显示的图。Mertens 融合不先估计相机响应曲线，直接融合曝光。另一条路径先估计相机响应曲线再合成。

## 阶段 12 · 应用：检测、识别、跟踪、文字、码

主线完成后做。同一章里带 `3dcam` 的脚本是深度相机版本，带 `npu` 的是 NPU 后端版本。普通摄像头先跑不带这两个后缀的文件。

### 人脸

教程 `Eleventh/10_1`、`10_2` 讲 Haar 特征和级联分类器：很多弱分类器串起来，前面的级联很快丢掉明显的背景窗口。`10_2` 是自己训练级联的数据准备过程。

书的对应关系：

- `haar_face.py`：`CascadeClassifier` 加 `detectMultiScale`，灰度图上画人脸框。
- `yunet_face.py`：用 `FaceDetectorYN` 加载检测模型，输出人脸框和关键点。
- `face_recognition.py`：`FaceDetectorYN` 检测，`FaceRecognizerSF` 提取特征，和已保存的人脸特征比分数。

先跑 Haar，再跑 YuNet。识别要先有一张已提取特征的人脸图。

### 跟踪

阶段 8 的 MeanShift、CamShift 已经是跟踪。这里补 `demo.py`：手选一个框，用 DaSiamRPN 在后续帧里更新框。把它当成「调用一个现成跟踪器」，不在这一阶段拆网络结构。

### 文字

- `mser.py`：用 MSER 找稳定区域，再按位置去掉重复框。这是经典文字候选。
- `text_detection_db.py`：DB 网络检测文字区域。
- `text_recognition_crnn.py`：DB 检测后再用 CRNN 识别字符。`crnn.py` 里写明中文模型可以识别数字、大小写字母和部分符号。

### 码

- `barcode.py`：检测并解码条形码，画出位置和内容。
- `qrcode.py`：`QRCodeDetector`。
- `wechat_qrcode.py`：来自 opencv_contrib 的微信二维码检测器。跑这个文件时安装 contrib 包。
